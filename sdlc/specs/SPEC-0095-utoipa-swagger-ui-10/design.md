## 1. Debt
### DBT-001: build time zip 3.0.0 kept alive by four accepted advisories
- **Current structure:** `utoipa-swagger-ui = { version = "9", features = ["axum"] }` and `utoipa = { version = "5", features = ["axum_extras"] }` (`Cargo.toml:113-114`) resolve to utoipa-swagger-ui 9.0.2 and a second zip, 3.0.0 (`Cargo.lock:6537`, `Cargo.lock:7092`). Four advisories on that zip are ignored in `.cargo/audit.toml:9-12` and `deny.toml:21-24`, each tagged `until BL-0059`.
- **Cost paid today:** a standing security acceptance, a second zip major in the graph, and three tests (`security_gate.rs:149,182,223`) that freeze the exception in place.
- **Target structure:** utoipa-swagger-ui 10.x (build dependency `zip ^9.0`) and utoipa 6.x; one zip in the lock, 9.x; no zip advisory ignored.
- **Observable behavior:** unchanged for the REST plane. The Swagger UI static assets embedded in the crate may be a newer Swagger UI release; no test pins their bytes (DEC-002).

## 6. Decisions
- **DEC-001:** bump `utoipa` to 6 and keep `axum_extras`. **Alternatives considered:** drop the unused direct dependency (no `utoipa::` use in source), rejected here: unrelated to the debt, it changes the manifest beyond the trigger; reported as a side finding. Keep `utoipa` 5 beside swagger-ui 10 (rejected: two utoipa majors, the crate requires `^6`). **Rationale:** smallest manifest delta that resolves, shown by the trial run. **Implemented by:** DR-001. **Evidence:** `Cargo.toml:113`.
- **DEC-002:** accept that the embedded Swagger UI static assets may change with the crate. **Alternatives considered:** vendor and serve our own copy (rejected in BL-0059: larger change for a build time acceptance). **Rationale:** assets are third party static files; the Swagger tests assert the page and base href, not bytes (`openapi.rs:2001-2002`). **Implemented by:** n/a, no code impact. **Evidence:** `openapi.rs:1986-2030`.
- **Assumption:** `make security` and the tests run with `cargo-audit` and `cargo-deny` installed; when absent the existing tests skip (`security_gate.rs:21-27`).
