# Discovered drift: removing `on_conflict` moved 17 shipped tests, not the 6 declared

> Discovered during: US-007 implementation (commit 227accc)
> Originating artifact: the specification's Affected Tests table and its Modified/Removed test sections
> Nature: under-stated blast radius in the specification, not an implementation defect

## What the specification declared

Six shipped tests were listed as affected by removing the `on_conflict` parameter from
`git.remote_pull`: four rewritten (`e2e_new_118`, `e2e_new_125`, `e2e_new_128`,
`e2e_new_129`) and two deleted (`e2e_new_117`, `e2e_new_126`).

## What implementation actually required

Seventeen. Beyond the declared six, ten further shipped tests referenced the parameter or
the refusal behaviour and had to be adapted with their intent preserved (content, parents,
atomicity, quota accounting, conflict-marker absence): `e2e_new_123`, `127`, `130`, `134`,
`136`, `137`, `139`, `140`, `182`, plus an in-file schema assertion.

One further test was **deleted** beyond the declared list: `e2e_new_135`, whose entire
subject was `on_conflict`'s value validation. That validation no longer exists; the
equivalent check on `git.merge_resolve`'s `strategy` was already delivered by US-003.

## Why the specification under-counted

The Affected Tests table was built from tests whose names or descriptions named the
diverged-pull behaviour. It did not include tests that merely passed `on_conflict` while
asserting something else, such as quota accounting or marker absence. Removing a parameter
touches every caller, not only the tests about that parameter.

## Decision needed from the user

Whether `e2e_new_135`'s deletion should be recorded in the specification's Removed Tests
section. The implementer did not edit the specification, correctly: a specification is not
reconciled to match what implementation discovered.

Recommendation: accept as-is. The deletion is justified and its replacement coverage exists.
Record it if the specification is ever revised for another reason; do not revise it solely
for this.
