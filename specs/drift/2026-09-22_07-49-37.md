# Discovered drift: six acceptance tests were homed to a story that cannot run them

> Discovered during: US-002 implementation (commit 386e58c)
> Originating artifact: specs/stories/_index.md and the US-002 story file
> Nature: partition defect in /plan-spec, not a specification defect

## What happened

`US-002` carries 36 acceptance tests. Six of them invoke tools that later stories build,
so they cannot be written or run inside US-002:

| Test | Needs | Built by |
|---|---|---|
| E2E-NEW-542 | `git.merge_resolve` | US-003 |
| E2E-NEW-552 | `git.merge_resolve` ("row removed on successful resolve") | US-003 |
| E2E-NEW-553 | `git.merge_abort` ("row removed on abort") | US-003 |
| E2E-NEW-616 | `git.rebase` | US-013 / US-015 |
| E2E-NEW-618 | `git.rebase` | US-013 / US-015 |
| E2E-NEW-953 | all five operation types present | US-019 or later |

The US-002 sub-agent implemented the other 30, reported the six honestly rather than
faking them, and did not widen its scope to build the missing tools.

## Why the partition missed it

`/plan-spec` ran a floor check whose detector matched tool tokens such as `merge_resolve`
and `git.rebase`. It did not match the bare verb forms these six test descriptions use,
for example "row removed on successful resolve" and "row removed on abort". The first
version of that detector missed the same class more widely and was strengthened once; this
is the residue it still did not catch.

## Resolution applied during this run

The six tests are carried forward to the story that builds the tool each one needs, by
instructing that story's sub-agent explicitly. No story file and no index row was rewritten:
re-homing a test is `/plan-spec`'s authority, not the implementer's.

Phase 4.6 CONVERGE is the backstop: it audits every requirement against the whole lot, so a
test that is never picked up surfaces there as a gap rather than disappearing.

## Decision needed from the user

None to unblock this run. For the next partition: the floor detector should match bare
verbs, not only `tool.name` tokens. Worth recording against `/plan-spec` rather than against
this specification, which is not at fault.
