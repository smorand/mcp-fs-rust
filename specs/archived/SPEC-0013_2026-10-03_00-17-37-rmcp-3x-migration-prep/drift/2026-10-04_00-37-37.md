# Discovered drift: Phase 4.6 converge found DR-003's literal bar still unmet for `Args`, now
closed

> Discovered during: Phase 4.6 converge audit (independent auditor sub-agent)
> Originating register entry: none (new discovery, follow-on from drift/2026-10-03_02-05-00.md)

## What was found

An independent converge audit, run after all 14 stories were marked done, found that
`crates/core/src/mcp/server.rs`'s 49 git.*/git.auth*/git.pr_* `#[tool]` methods called
`pub(crate)` functions in `tools/{git,git_auth,git_pr}.rs` typed as
`(ctx: ToolCtx, a: registry_support::Args)` — a real, undisclosed production use of `Args`,
which DR-003 explicitly names as forbidden outside test code. `tools/editor.rs`'s `register()`
was also found compiled into production (unreachable, but not `#[cfg(test)]`-gated).

## Resolution

All 49 functions were converted to take typed `Parameters<T>` fields directly (the same pattern
already used by `fs.*`/`admin.*`), matching the structs rmcp's schemars derive already builds at
the `#[tool]` method boundary. `server.rs`'s methods no longer wrap typed fields into `Args` just
to unwrap them again (net code reduction, -357 lines in `server.rs` alone). The `#[cfg(test)]`-
gated `register()`/`register_with()` closures (used only by the shared test harness) now
deserialize JSON into the same typed struct themselves, preserving every existing raw-JSON-based
validation test (bogus enum strings, non-array fields, etc.) exactly. `editor.rs::register()` is
now `#[cfg(test)]`-gated.

`ToolCtx` was NOT converted away: re-reading DR-003's literal text ("no `ToolRegistry`,
`ToolSchema`, `Args` or `ToolHandler` symbol SHALL remain referenced outside test code") shows
`ToolCtx` was never in the forbidden list. Its production survival (as the carrier of
`state`/`person` into the typed git functions) is compliant with DR-003 as written, not a gap.

## Verification

`cargo build --workspace --all-features` clean. `cargo test --workspace --all-features`: 2102
passed, 0 failed (unchanged from before this fix — pure internal refactor). `cargo fmt --all --
check` clean. `cargo clippy --all-targets --all-features -- -D warnings` clean.
`rg -n "registry_support::Args" crates/core/src/mcp/server.rs` returns zero matches.

## Not a spec edit

Per Invariant 6 / Section D, `spec.md` is not modified beyond its already-permitted
`Status`/register `Status` fields. This drift file is the record.
